# 🚗 Electric Vehicle Market Performance & Insights

## 📌 Project Overview
This project focuses on analyzing Electric Vehicle (EV) market performance using Tableau. The dashboard provides insights into EV sales, manufacturers, vehicle categories, battery technologies, driving range, customer ratings, and manufacturing countries.

The goal is to understand EV market trends through interactive visualizations and data analysis.

## 🎯 Objectives
- Analyze total EV sales by manufacturer.
- Explore the distribution of battery technologies.
- Compare EV sales across vehicle categories.
- Understand the relationship between battery capacity and driving range.
- Compare average customer ratings by vehicle category.
- Analyze EV sales by manufacturing country.

## 🛠️ Tools & Technologies
- **Tableau Public** — Data visualization and interactive dashboard creation.
- **CSV Dataset** — Data source for analysis.
- **GitHub** — Project documentation and sharing.

## 📊 Dashboard Features
The dashboard includes six visualizations:
1. Total EV Sales by Manufacturer
2. Battery Technology Distribution
3. Total EV Sales by Vehicle Category
4. Battery Capacity vs. Driving Range
5. Average Customer Rating by Vehicle Category
6. Total EV Sales by Manufacturing Country

It also includes filters to explore the data by manufacturer and year.

## 📁 Dataset
The project uses a CSV dataset containing information about EV manufacturers, models, battery capacity, driving range, annual sales, prices, customer ratings, and charging speeds.

**Note:** If you are using the sample dataset created for this project, the data is synthetic and intended for practice and demonstration. It should not be treated as official EV market statistics.
